contexto

El objetivo de este proyecto es desarrollar un programa que calcule de forma automática el pago de un empleado a partir de su puesto y el total de horas trabajadas.

creo que es interesante por Es una herramienta práctica que automatiza el cálculo de nómina básica, reduciendo errores manuales y permitiendo gestionar de forma ágil diferentes esquemas salariales según el rol del trabajador.

algoritmo
selecciona tu posicion de una lista
(cada posicion tiene un salrio por hora)
inserta cuantas horas trabajaste
horas trabajadas*posicion
podria añadir despues multiplicadores por horas extra o por dias festivos
